# Sale

## Назначение
Продажа товара со склада покупателю.

## Endpoint
POST /sales

## Роли и доступ
- cashier
- manager

## Входные данные
- product_id — UUID
- quantity — int (>0)
- price — decimal

## Бизнес-правила
- нельзя продать больше остатка
- цена не может быть ниже закупочной
- склад должен быть открыт

## Сайд-эффекты
- уменьшается остаток
- создаётся SaleEvent
- обновляется отчёт по продажам

## Возможные ошибки
- 400 — некорректные данные
- 409 — недостаточный остаток
- 403 — нет доступа

## Пример
```json
{
  "product_id": "...",
  "quantity": 2,
  "price": 120.50
}
